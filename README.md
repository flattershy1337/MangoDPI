# MangoDPI 2.0

**MangoDPI — инструмент для исследования и диагностики DPI-фильтрации с графическим интерфейсом.**

Программа построена на winws ([zapret](https://github.com/bol-van/zapret)) и стратегиях [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) 1.10.4. Она позволяет проверить, как разные методы модификации сетевых пакетов взаимодействуют с системами глубокой инспекции трафика (DPI). Исходный код полностью открыт, лицензия MIT.

> Перед использованием прочитайте [пользовательское соглашение]((https://github.com/flattershy1337/MangoDPI/blob/main/EULA[1].txt)). Программа предназначена для исследовательских и образовательных целей. Пользователь самостоятельно отвечает за соблюдение законодательства своей страны.

## Возможности

- **Одна кнопка**: включить или выключить модификацию трафика.
- **Автоподбор**: MangoDPI по очереди проверит 22 стратегии на тестовых адресах из `utils\targets.txt` и включит ту, что показала лучший результат.
- **Автозапуск** вместе с Windows (служба) одним переключателем.
- **Списки**: домены, к которым применяется стратегия, исключения, IP-исключения.
- **Темы Material 3**: Манго, Океан, Лес, Виноград, Сакура, Графит, цвет акцента Windows или любой свой цвет. Режимы: тёмный, светлый, системный.
- **Обслуживание**: обновление списков, диагностика сетевых конфликтов с кнопкой «исправить», журнал.
- **Установщик, автообновление и полное удаление**: все изменения в системе отменяются.

## Установка

**Установщик:** скачайте `MangoDPI-Setup.exe` из [Releases](https://github.com/flattershy1337/MangoDPI/releases) и запустите. Он скачает последнюю версию, сверит контрольную сумму и установит программу в `Program Files`. Ярлыки появятся в «Пуске» и на рабочем столе, программа — в «Установленных приложениях».

**Портативно:** скачайте `MangoDPI-x.y.z.zip`, распакуйте **целиком** и запустите `MangoDPI.exe`. Позже её можно установить кнопкой «Настройки → Установить в систему».

При первом запуске программа покажет пользовательское соглашение. Без его принятия она не работает.

Обновления: «Доступна MangoDPI x.y.z → Обновить». Ваши списки и настройки сохраняются.

**Удаление:** «Настройки → Удалить MangoDPI» или «Параметры Windows → Приложения → MangoDPI → Удалить». Удаляются служба, драйвер WinDivert, записи в hosts, ярлыки и папка программы, а параметр TCP timestamps возвращается к исходному значению.

Требования: Windows 10/11 x64, .NET Framework 4.7.2+ (уже есть в системе), права администратора (нужны драйверу WinDivert).

Если раньше стояла MangoDPI 1.0 или zapret-discord-youtube, программа найдёт старую службу `zapret` и предложит её удалить.

## Изменения по сравнению с 1.0

- Стратегии и fake-пакеты обновлены до zapret-discord-youtube 1.10.4: 22 стратегии вместо 9.
- Исправлена стратегия FAKE TLS AUTO: она не запускалась (winws: `could not mod tls`).
- Удалена функция «Скрытие IP / TTL»: она нарушала работу всех стратегий.
- Исправлены удаление записей из списков, тесты и обновление IPSet.
- Графический интерфейс вместо BAT-меню, установщик, автообновление, удаление.

## Структура

```
MangoDPI.exe              приложение (без bin\ рядом работает как установщик)
bin\                      winws.exe, WinDivert, fake-пакеты
lists\                    списки (*-user.txt — пользовательские)
strategies\*.strat        стратегии (формат: order / title / description / args)
utils\                    настройки и адреса для автоподбора (targets.txt)
EULA.txt                  пользовательское соглашение
LICENSE.txt               лицензия MIT
THIRD-PARTY-NOTICES.txt   лицензии сторонних компонентов
```

## Сборка и релиз

`build.bat` собирает `package\MangoDPI.exe` компилятором C#, встроенным в Windows (.NET Framework 4.x); Visual Studio не нужна. `release.ps1` готовит файлы для GitHub-релиза, порядок описан в [docs/RELEASING.md](docs/RELEASING.md). Планы развития — в [docs/ROADMAP.md](docs/ROADMAP.md).

`MangoDPI.exe --selftest <папка>` проверяет все стратегии через `winws --dry-run` и сохраняет скриншоты интерфейса.
